# Hardware-Aerodynamics-Expansion

Hardware and Aerodynamics Expansion

This repository contains the mechanical and electrical design files for a Continuing Professional Development project at the University of Nottingham. The project encompasses custom aerodynamic surfacing and printed circuit board development.

Aerodynamic Surfacing

- Designed a performance enhancing front nosecone assembly using Autodesk Inventor.
- Incorporated a swept main plane, secondary flaps, and vertical endplates into the CAD model.
- Engineered the assembly geometry to optimize airflow and increase front tyre ground effect during cornering.

Printed Circuit Board Design

- Developed a highly size efficient custom printed circuit board using KiCad schematic capture and layout tools.
- Integrated a stable voltage divider and gain amplifier circuit directly into the board architecture.
- Selected and routed surface mount resistors alongside ceramic and electrolytic decoupling capacitors.
- Designed the electrical layout to create a stable reference voltage while actively mitigating high frequency electrical noise.
